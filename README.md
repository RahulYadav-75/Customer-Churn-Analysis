# Customer Churn Analysis

## 📌 Project Overview

**Customer Churn Analysis** is a data analysis project that explores customer behavior and identifies the key factors that may lead to customer churn.

The project uses **Python, SQL, Pandas, NumPy, Matplotlib, and Seaborn** to clean, analyze, and visualize customer data.

## 🎯 Objectives

- Analyze customer churn patterns.
- Identify factors related to customer churn.
- Perform data cleaning and preprocessing.
- Explore customer demographics and service usage.
- Find important business insights.
- Create visualizations to understand churn behavior.
- Provide recommendations to reduce customer churn.

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Seaborn**
- **SQL**
- **Jupyter Notebook**
- **PostgreSQL / SQLite**

## 📂 Project Workflow

### 1. Data Understanding
- Load the customer dataset.
- Check rows and columns.
- Understand data types.
- Analyze basic statistics.

### 2. Data Cleaning
- Handle missing values.
- Remove duplicate records.
- Correct data types.
- Check inconsistent values.

### 3. Exploratory Data Analysis (EDA)

The analysis includes:

- Customer churn distribution.
- Churn by gender.
- Churn by age.
- Churn by tenure.
- Churn by contract type.
- Churn by payment method.
- Churn by monthly charges.
- Churn by internet service.
- Churn by customer services.

### 4. Data Visualization

Different charts are used to understand customer behavior:

- Bar Charts
- Count Plots
- Histograms
- Box Plots
- Pie Charts
- Correlation Heatmap

## 📊 Key Analysis

The project focuses on answering questions such as:

1. What percentage of customers have churned?
2. Which customer groups have higher churn?
3. Does customer tenure affect churn?
4. Which contract type has the highest churn?
5. Which payment method is associated with higher churn?
6. How do monthly charges affect churn?
7. Which services are commonly used by churned customers?
8. What factors are strongly related to customer churn?

## 💡 Business Insights

The analysis helps businesses understand:

- Customer groups with high churn risk.
- Services associated with customer retention.
- Pricing and billing patterns.
- Contract-related churn behavior.
- Customer characteristics linked with churn.

## 📈 Recommendations

Based on the analysis, businesses can:

- Offer special plans to high-risk customers.
- Improve customer support.
- Provide attractive long-term contracts.
- Give personalized offers.
- Monitor customers with high monthly charges.
- Improve services that have high churn rates.
